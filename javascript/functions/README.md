# Variables and Strings Projects

This folder contains projects focused on JavaScript functions. These exercises reinforce declaring functions and managing scope.

## Projects

### Calculator
**Description**:  
Build a basic calculator. Practice defining and invoking functions.

### Boolean Check Function
**Description**:  
Build a function that checks if a value is classified as a boolean primitve.

---

Each project is self-contained within its own folder and includes a `script.js` file.
