# Booleans and Numbers Projects

This folder contains projects focused on booleans and numbers. These exercises reinforce JavaScript numbers, arithmetic, comparison and boolean operators, and conditonal logic.

## Projects

### Logic Checker
**Description**:  
Practice working with conditional statements and comparison operators.

### Mathbot
**Description**:  
Practice working with different `Math` object methods. Includes `random`, `floor`, `ciel`, `round`, `max`, and `min`.

---

Each project is self-contained within its own folder and includes a `script.js` file.
