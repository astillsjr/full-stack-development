# HTML Certification Projects

This folder holds certification projects for the HTML curriculum. These are milestone builds that demonstrate what you can do after completing related lessons, separate from smaller practice labs.

## Projects

### Survey Form
**Description**:  
Build a complete survey form as a certification project. Practice required fields, email and number inputs, radio buttons, checkboxes, a dropdown, a textarea, and a submit button with accessible labels.

---

Each project is self-contained within its own folder and includes an `index.html` file.
