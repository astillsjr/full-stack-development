# Flexbox Projects

This folder contains projects focused on CSS Flexbox. These exercises reinforce how flex containers arrange, wrap, align, and space their items to build flexible layouts.

## Projects

### Photo Gallery
**Description**:  
Build a responsive photo gallery. Practice `display: flex`, `flex-wrap`, `justify-content`, `align-items`, and `gap`, plus `object-fit: cover` to crop images into uniform tiles.

### Colorful Boxes
**Description**:  
Arrange a set of colored boxes in a wrapping flex layout. Practice the `flex` shorthand, `flex-grow`, `flex-shrink`, `order`, `align-content`, and nested flex columns inside each box.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
