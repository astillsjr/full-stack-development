# Positioning Projects

This folder contains projects focused on CSS positioning. These exercises reinforce `position`, offset properties like `top` / `left`, stacking with `z-index`, and centering positioned elements.

## Projects

### Cat Painting
**Description**:  
Draw a cat's face entirely with CSS. Practice `position: absolute` for every feature, centering by setting all four offsets to `0` with `margin: auto`, `z-index` layering, border tricks for triangle ears and nose, and `transform: rotate()`.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
