# CSS Certification Projects

This folder holds certification projects for the CSS curriculum. These are milestone builds that demonstrate what you can do after completing related lessons, separate from smaller practice labs.

## Projects

### Playing Cards
**Description**:  
Build a card table with a board and a hand of playing cards as a certification project. Practice nested Flexbox layouts, `align-self` for corner and center pips, `transform: rotate()` for mirrored symbols, and a full-page background image.

### Book Inventory App
**Description**:  
Build a book inventory table with read / to-read / in-progress rows and star ratings as a certification project. Practice attribute selectors (`[class="…"]`, `[class^="…"]`, `[class~="…"]`), descendant selectors for rate dots, and `linear-gradient` backgrounds.

### Technical Documentation Page
**Description**:  
Build a JavaScript documentation page with a fixed sidebar and section anchors as a certification project. Practice a fixed navbar, in-page links, `scroll-behavior`, a dark color theme, and a media query for reduced motion.

### Product Landing Page
**Description**:  
Build a FocusPulse product landing page as a certification project. Practice a sticky header, in-page navigation, an email signup form, feature rows, an embedded demo, pricing cards, and a media query for reduced motion.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
