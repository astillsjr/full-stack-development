# Accessibility Projects

This folder contains projects focused on accessible styling with CSS. These exercises reinforce readable layouts, screen-reader-friendly techniques, and respecting user motion preferences.

## Projects

### Quiz Webpage
**Description**:  
Build an accessible HTML/CSS quiz. Practice a visually hidden `.sr-only` class, `prefers-reduced-motion` for smooth scrolling, `min()` / `max()` responsive sizing, labeled form controls, and landmark regions with `aria-labelledby`.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
