# Typography Projects

This folder contains projects focused on CSS typography. These exercises reinforce web fonts, font weights and sizes, relative units like `em` / `rem`, spacing, and text alignment.

## Projects

### Nutrition Label
**Description**:  
Recreate an FDA-style nutrition facts label. Practice Google Fonts, `font-weight`, `rem` / `em` sizing, `letter-spacing`, `text-indent`, and flex rows that push values to the right.

### Newspaper Article
**Description**:  
Style a humorous newspaper article. Practice font families, `rem` vs `em` sizing, `font-weight` and `font-style`, `text-transform`, `text-indent`, `line-height`, and a drop cap with `::first-letter`.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
