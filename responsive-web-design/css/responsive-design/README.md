# Responsive Design Projects

This folder contains projects focused on responsive design. These exercises reinforce media queries, adapting layouts across breakpoints, and sizing elements for different screen widths.

## Projects

### Piano
**Description**:  
Build a styled piano with white and black keys. Practice `float` for key layout, `::after` for black keys, `position` for the logo, and `@media` queries to shrink the piano at tablet and mobile breakpoints.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
