# Variables Projects

This folder contains projects focused on CSS custom properties. These exercises reinforce declaring variables on `:root`, reusing them with `var()`, and overriding them inside a media query.

## Projects

### City Skyline
**Description**:  
Build a city skyline with background and foreground buildings. Practice custom properties for building and window colors, `linear-gradient` and `repeating-linear-gradient`, border triangles, flex layout, and a media query that reassigns those variables for a night scene.

### Availability Table
**Description**:  
Build a weekly meeting availability table. Practice custom properties for the color scale and borders, `var()`, solid and dashed borders for hour and half-hour rows, and a legend gradient built from those same variables.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
