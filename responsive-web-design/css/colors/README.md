# Colors Projects

This folder contains projects focused on CSS color values and effects. These exercises reinforce named colors, hex, `rgb` / `rgba`, `hsl` / `hsla`, gradients, and shadows.

## Projects

### Colored Markers
**Description**:  
Build colored marker graphics with caps and sleeves. Practice `rgb`, `rgba`, hex, `hsl` / `hsla`, linear gradients, and box shadows.

### Colored Boxes
**Description**:  
Display a row of colored boxes using hex, `rgb`, named colors, and `hsl`. Practice a centered flex row with `gap` for even spacing.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
