# Absolute and Relative Units Projects

This folder contains projects focused on CSS sizing with absolute and relative units. These exercises reinforce viewport units, percentages, and other length values used to build flexible layouts.

## Projects

### Event Flyer Page
**Description**:  
Build an event flyer with a centered layout. Practice viewport-based sizing (`vw`, `vh`), percentage widths, and `min-height` for a full-page flyer feel.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
