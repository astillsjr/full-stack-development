# Styling Forms Projects

This folder contains projects focused on styling HTML forms with CSS. These exercises reinforce layout, field spacing, and control-specific selectors for usable registration and input UIs.

## Projects

### Registration Form
**Description**:  
Build a dark-themed registration form. Practice form width constraints, stacked labels/inputs, `.inline` radio/checkbox controls, and attribute selectors for submit and file inputs.

### Contact Form
**Description**:  
Build a centered contact form card. Practice flex centering, stacked labels/fields, rounded inputs, and a submit button with `:hover` feedback.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
