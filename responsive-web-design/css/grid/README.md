# Grid Projects

This folder contains projects focused on CSS Grid. These exercises reinforce `grid-template-columns`, `grid-column`, `grid-auto-flow`, and using media queries to restack a grid on smaller screens.

## Projects

### Magazine
**Description**:  
Build a magazine layout for an article about the freeCodeCamp curriculum. Practice CSS Grid for the page, hero, social icons, and image gallery, multi-column text, and media queries that stack the layout on smaller screens.

### Newspaper Layout
**Description**:  
Build a Daily Bugle front page with a masthead, two lead stories, a cover image, and three briefs. Practice `grid-template-areas`, a full-width header, container-query sizing with `cqw`, and borders and spacing around the stories.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
