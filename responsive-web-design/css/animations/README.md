# Animations Projects

This folder contains projects focused on CSS animations. These exercises reinforce `@keyframes`, the `animation` shorthand, `transform: rotate()`, and `transform-origin`.

## Projects

### Ferris Wheel
**Description**:  
Build a spinning Ferris wheel with spokes and cabins. Practice `@keyframes` for the wheel and cabin motion, `animation-timing-function`, and `transform-origin` so the cabins counter-rotate and stay upright.

### Moon Orbit
**Description**:  
Build an earth with a moon circling it. Practice absolute centering, a linear infinite `@keyframes` animation, and combining `translate()` with `rotate()` so the orbit stays centered.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
