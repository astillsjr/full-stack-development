# Attribute Selectors Projects

This folder contains projects focused on CSS attribute selectors. These exercises reinforce targeting elements by their attributes, such as exact matches with `[attr="value"]` and word matches with `[attr~="value"]`.

## Projects

### Balance Sheet
**Description**:  
Build an accessible balance sheet with tables for assets, liabilities, and net worth. Practice attribute selectors like `span[class~="sr-only"]` and `tr[class="total"]`, a sticky year header, `border-collapse`, and screen-reader-only text.

---

Each project is self-contained within its own folder and includes an `index.html` file, along with a linked CSS file `styles.css` to showcase the applied styles.
